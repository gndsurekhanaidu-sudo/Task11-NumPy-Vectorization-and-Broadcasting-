# Task11-NumPy-Vectorization-and-Broadcasting-
Objective
Perform arithmetic operations on complete NumPy arrays and understand broadcasting between compatible array shapes.
Tools Used
Python
NumPy
Jupyter Notebook
Tasks Completed
Performed vectorized arithmetic operations on NumPy arrays.
Added a scalar value to an array.
Practiced at least three broadcasting examples using compatible array shapes.
Compared loop-based calculations with vectorized calculations.
Key Learning
Vectorization performs operations on entire arrays without writing explicit Python loops. Broadcasting allows NumPy to perform operations on arrays with compatible shapes.
Example
import numpy as np

a = np.array([1, 2, 3])
print(a + 5)
print(a * 2)
Output:
[6 7 8]
[2 4 6]
Conclusion
Learned how NumPy vectorization and broadcasting make numerical calculations simpler and more efficient.
